# Recipe Book

A responsive recipe app built with React and Tailwind CSS. Browse recipes, filter by cuisine, search by name, and open a recipe for its ingredients and step-by-step instructions.

## Features

- Home, recipes, and About pages
- Cuisine filters and recipe search
- Nested recipe detail pages at `/recipes/:slug`
- Lazy-loaded About and recipe detail pages with `React.lazy` and `Suspense`
- Responsive layout styled with Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
